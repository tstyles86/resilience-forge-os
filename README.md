# Resilience Forge OS
Travis Sanders' personal AI operating system — content, coaching, advocacy, book, ideas, and calendar.

See **DEPLOY_GUIDE.md** for full setup. Quick version:
1. Get an Anthropic API key (console.anthropic.com)
2. Upload these files to a GitHub repo
3. Import the repo on Vercel, add ANTHROPIC_API_KEY as an environment variable, Deploy

Local dev: `npm install` then `npm run dev`
